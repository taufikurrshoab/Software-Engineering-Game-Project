01 / QUICK CONCEPT

What is DFS?

Pick one path and follow it as deep as you can. At a dead end, step back and try the next path.

DFS · Stack · LIFO

Go deep first: DFS follows one path as far as it can before trying any other. It explores one branch completely, then moves to the next branch. Unlike BFS, it does not visit nodes level by level.

TIME COMPLEXITY O(V + E)

Each node is pushed and popped once, and each edge is checked at most twice. V = nodes, E = edges.

SPACE COMPLEXITY O(V)

The visited set and the stack hold at most V nodes. The stack is deepest when the graph is one long path.
