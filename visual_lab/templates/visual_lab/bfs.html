01 / THEORY

Theory

Breadth-First Search (BFS) is a graph traversal algorithm that explores nodes level by level, starting from a selected node. It visits all nearby neighbours before moving to the next level. BFS uses a Queue data structure that follows FIFO (First In, First Out). It is also useful for finding the shortest path in an unweighted graph.

BFS · Queue · FIFO

Level by level: BFS visits every node 1 step from the start, then every node 2 steps away, and so on. This is why BFS finds the shortest path (fewest edges) in an unweighted graph.
