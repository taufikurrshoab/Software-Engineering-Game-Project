What is A* Search?

A* is a best-first graph search that finds a lowest-cost path from a start node to a goal node. It always expands the open node that looks cheapest overall, using the cost so far plus an estimate of the cost still to go.

f(n) calculator

f(n) = g(n) + h(n) = 10

Dijkstra and A*

DijkstraA*
Next nodelowest glowest g + h
Knows the goalnoyes, via h
Explorationall directionsleans toward goal
Optimal pathyesyes, if h is admissible

With h(n) = 0 for every node, A* behaves exactly like Dijkstra.

Complexity

Time
O(E log V) with a binary heap in the worst case. A good heuristic expands far fewer nodes.
Space
O(V), because open and closed sets can hold every node.
