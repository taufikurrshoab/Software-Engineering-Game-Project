Bellman-Ford Visualizer

Bellman-Ford finds the shortest paths from a single source, even when edges have negative weights, and it can detect negative-weight cycles that make shortest paths undefined.

01

THEORY

Understand the idea first

Bellman-Ford works by edge relaxation. It starts by assuming every node except the source is unreachable (distance Infinity), then scans every edge in the graph again and again. Each time an edge u → v offers a shorter route to v than the one currently known, the distance of v is improved. A shortest path uses at most V - 1 edges, so V - 1 full passes are enough. One extra scan tells us whether a negative cycle is still improving distances.

Weighted Graph

A graph is a set of nodes (vertices) connected by edges. In a weighted graph every edge carries a number called its weight, such as distance, cost or time. In Bellman-Ford the graph is directed: an edge A → B can only be travelled from A to B.

Weights may be positive, zero or negative. A negative weight can model a refund, a discount or an energy gain, which is why Dijkstra's algorithm cannot be used here but Bellman-Ford can.

A → B costs 4. B → C costs -2, so the route A → B → C costs 2.

Edge Relaxation

Relaxing an edge (u, v, w) asks one question: is going through u a shorter way to reach v? If dist[u] + w < dist[v], then dist[v] is replaced by dist[u] + w and prev[v] is set to u.

If dist[u] is still Infinity, u has not been reached yet, so the edge is skipped.

3 + 4 = 7 7 < 10 is true

Relaxation succeeds: dist[v] becomes 7 and prev[v] becomes u.

Negative Cycle Detection

A negative cycle is a loop of edges whose weights add up to less than zero. Each trip around the loop makes the total cost smaller, so there is no true shortest path to any node it can reach.

After V - 1 passes, all shortest distances should be final. If one more scan can still relax an edge, a reachable negative cycle exists. Cycles that cannot be reached from the source are ignored.

In an undirected graph, a single negative edge already forms a negative cycle, because it can be walked back and forth in both directions.

The loop A → B → C → A costs 2 + 1 - 5 = -2. Every lap lowers all distances on it by 2.

Total cost of the cycle so far: 0 laps, cost 0.

Time Complexity

O(V × E)

Up to V - 1 passes, and each pass scans all E edges.

Space Complexity

O(V + E)

Distance and predecessor arrays take O(V); the edge list takes O(E).

What V and E mean

V
Number of vertices (nodes) in the graph.
E
Number of directed edges in the graph.

Please fix the following

    Edge format

    SOURCE-DESTINATION:WEIGHT

    A-B:-2

    A directed edge from A to B with weight -2.

    • Direction goes from the first node to the second. B-A is a different edge from A-B.
    • Weights can be positive, zero, negative or decimal, for example C-D:-1.5.
    • Every node used in an edge must appear in the Nodes field.
    • Self-loops (A-A:3) are allowed. A negative self-loop is a negative cycle.
    • Blank lines are ignored. Lines starting with # are treated as comments.
