      APPLICATIONS

      Where Minimax is used

      Minimax suits any game with two players who take turns, where one player's gain is the other's loss and every position is visible. Real programs rarely search to the end of the game, so they stop at a fixed depth and score the position with an evaluation function instead of a final win or loss.

      Chess

      Engines search many moves ahead and score positions by material, piece activity and king safety. The tree is huge, so Minimax is combined with alpha-beta pruning.

      Checkers

      Forced captures make the tree narrow enough to search deeply. Checkers has been fully solved with search methods that build on Minimax.

      Tic Tac Toe

      The game is small enough to search completely, so Minimax plays perfectly: the best an opponent can do against it is a draw.

      Adversarial decision-making

      Any situation with a rational opponent can be modeled this way, such as security planning, bidding, or choosing a strategy that limits the worst-case loss.
