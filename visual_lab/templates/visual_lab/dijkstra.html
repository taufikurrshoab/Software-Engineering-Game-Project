01 / QUICK CONCEPT

Theory

Dijkstra's algorithm finds the cheapest route from one source node to every other reachable node in a weighted graph.

Dijkstra · Priority Queue · Greedy

Weighted graph: every edge has a weight, which is the cost of travelling along it (distance, time or price). The cost of a path is the sum of its edge weights, not the number of edges. Dijkstra needs every weight to be 0 or more.

TIME COMPLEXITY O((V + E) log V)

Adjacency list with a binary min-heap. V = number of nodes, E = number of edges (connections).

SPACE COMPLEXITY O(V + E)

Stores the graph, the distance and previous-node tables (V each) and the heap (up to E entries).
