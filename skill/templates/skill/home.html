How it works

Three steps to get started

  1. 01

    Add a skill

    Add anything you are learning or already know, like Python or HTML.

  2. 02

    Set your progress

    You decide the percentage, from 0 to 100. Your status follows it automatically.

  3. 03

    Grow your tree

    Place skills under parents, such as Django under Python, and build the tree over time.

Manual progress tracking

No quizzes and no automatic scoring. You set the number, and the status changes with it: 0% is not started, 1 to 99% is in progress, and 100% is completed.

Simple recommendations

When you complete a skill, ThinkSphere suggests what could come next. For example, after Python you may see Django and Machine Learning. You choose whether to add them, and your tree never changes on its own.

Example: Python done → Django → Machine Learning

Projects linked to skills

Record what you build and link it to the skills it used. Projects appear next to the skills they prove.
